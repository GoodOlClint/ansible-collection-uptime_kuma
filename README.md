# goodolclint.uptime_kuma

Ansible collection for managing Uptime Kuma monitors via its API.

## Requirements

- ansible-core >= 2.14
- Python >= 3.9
- No additional pip dependencies required

## Installation

```bash
ansible-galaxy collection install goodolclint.uptime_kuma
```
